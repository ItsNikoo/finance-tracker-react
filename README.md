# Finance Tracker React

UI-заготовка на React, TypeScript и Vite с Tailwind CSS 4.

Сохранены формы входа и регистрации, кнопки, стили и модальное окно. Поля доступны для ввода. Модальное окно закрывается крестиком, нажатием Escape или кликом по фону.

Формы не отправляют данные и не перезагружают страницу. Авторизация, проверка сессии, валидация и запросы к серверу удалены. Backend и переменные окружения не требуются.

## Запуск и проверка

```bash
npm install
npm run dev
npm run build
npm run lint
npm run preview
```

## Структура

- `src/UI/` — Button, ModalWindow, LoginForm и RegisterForm.
- `src/App.tsx` — компоновка интерфейса и состояние модального окна.
- `src/index.css` — глобальные стили и цвета темы.
- `src/main.tsx` — точка входа.
